## 这个项目是什么

| 项目 | 内容 |
|---|---|
| 开发板 | STM32F407ZGT6（WK-56-103）|
| 屏幕 | ILI9341 320x240，FSMC 并口，横屏 |
| 传感器 | MPU6050（软件 I2C，PB8=SCL / PB9=SDA，AD0 接 GND → 地址 0x68）|
| 功能 | 屏幕中间画靶心圆 + 气泡跟随重力移动，下方打印俯仰角/横滚角/角速度/温度/帧率 |
| 算法 | 加速度计 `atan2` 求绝对倾角 + 陀螺仪积分，**互补滤波**（K=0.98）融合 |

| 第二套 | 车身灯光控制单元（BCM）原型 | 多状态并发、**优先级仲裁**、**状态恢复** | [命题规范](出题设计/智能汽车情景题-两套.md#题一车身灯光控制单元bcm原型) |
| 第三套 | 泊车辅助提示系统（PDC） | **定量映射**、**时域间隔调制**、平滑滤波 | [命题规范](出题设计/智能汽车情景题-两套.md#题二泊车辅助提示系统pdc) |

**三套共同硬性约束**：全程禁用定时器（含 SysTick）、按键必须用 EXTI、不按 RESET 一次演示完。

> 第三套的思辨点：倒车雷达"越近越急"其实是**改周期不改脉宽**——和 PWM 调光改占空比恰好相反，人耳感知的是节奏而不是能量占比。
