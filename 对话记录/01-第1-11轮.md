## 二、技术路线（关键决策）

1. **不用 eMPL/DMP 库，自己写互补滤波。** DMP 是为四轴飞行器那种需要 yaw 的姿态解算设计的，文件多、代码大（有撞 MDK-Lite 32KB 代码上限的风险），而且水平仪本质上要的是**重力方向**。所以：
   - 加速度计 → 绝对倾角（无漂移，水平仪的基准）
   - 陀螺仪 → 短期角速度，补偿加速度计的抖动
   - `angle = K·(angle + gyro·dt) + (1-K)·accel_angle`，K=0.98，dt=10ms
   - 陀螺仪零偏在开机时静止采样 200 次自动标定；加速度计零偏做成"一键归零"
2. **一帧只重画会变的东西。** 静态背景（顶栏、面板框、标签、刻度圈）只画一次；每帧只重画 ① 靶心区域（约 176×176 的渐变底 + 圆环 + 刻度 + 十字 + 气泡）② 变化的数字（值不变就不重画，避免闪烁）。实测这个策略在 FSMC 上能跑 40~60fps。
3. **文字全用 ASCII + 图形**，不碰 `font.H` 里那套中文字库。原因是上一轮有人把工程 GBK↔UTF-8 来回转过（`backup_gbk/`、`utf8_restored/` 就是痕迹），中文字库数组有被转码搞坏的风险；而且仪器风格界面用英文标签更耐看。
4. **不破坏你现有工程**：新建独立目录 `陀螺仪水平仪\`，从原始 zip 里那份干净的 37 号工程复制，不动 `33-FSMC-TFTLCD显示实验\`。

`level.c` 内部分层：

| 层 | 函数 | 职责 |
|---|---|---|
| 取数 | `LEVEL_IMU_Read()` | 一次突发读 14 字节(0x3B~0x48)：加速度+温度+角速度，省 I2C 事务 |
| 解算 | `LEVEL_Update()` | 量程换算(±2g/±2000dps) → 互补滤波 → pitch/roll/合成倾角/水平判定 |
| 校准 | `LEVEL_CalibrateGyro()` / `LEVEL_Zero()` | 陀螺零偏开机标定 / 一键归零（当前姿态记为 0°） |
| 画图 | `LCD_FillCircle` `LCD_DrawRing` `LCD_DrawRoundRect` `LCD_Bar` | 驱动里没有的绘图原语，自己补 |
| 界面 | `UI_Splash()` `UI_DrawStatic()` `UI_DrawDynamic()` | 启动动画 / 静态底图 / 每帧动态层 |
| 工具 | `fmt_angle()` `fast_atan2()` | 自己格式化数字，不引 sprintf；避免依赖 libm |

## 四、UI 界面设计（横屏 320×240）

```
┌─────────────────────────────────────────────────────────────┐
│ SPIRIT LEVEL          ╭──────╮                              │ ← 顶栏：深蓝渐变 + 状态胶囊
│ 水平仪 MPU6050        │ LEVEL│        MPU6050  30.4°C 58fps │
├──────────────────────────────┬──────────────────────────────┤
│         ╭──────────╮         │  PITCH  前后(俯仰)            │
│       ╭─┤  · · ·   ├─╮       │        +0.3°                 │ ← 32号大字
│       │ │  ╭───╮   │ │       │  ROLL   左右(横滚)            │
│       │ │  │ ◎ │   │ │       │        -1.2°                 │
│       ╰─┤  ╰───╯   ├─╯       │  ├────●────┤  0.5°量程条      │
│         ╰──────────╯         │  GX +0.4  GY -0.2  GZ +0.1   │
│          靶心水平泡            │  合成倾角  1.2°   <1.0° 水平  │
├──────────────────────────────┴──────────────────────────────┤
│ KEY0:CAL   KEY1:HOLD   KEY_UP:FILTER              100Hz 采样  │
└─────────────────────────────────────────────────────────────┘
```

- **靶心**：外圈机加工感的刻度环（每 15° 小刻度、每 90° 长刻度）→ 中间黄靶环(±1.5° 区域) → 内圈绿靶心(±0.5°) → 十字准星 + 中心圆点。
- **气泡**：三层同心实心圆做径向渐变 + 左上高光点，靠 `pitch/roll × 每度像素数` 移动并钳位在环内。进绿靶心变**绿**、黄靶环内变**琥珀**、出圈变**红**——同时顶栏胶囊文字在 `LEVEL / NEAR / TILT` 之间切换。
- **配色**：底色 `#0A0E14`，面板 `#121821`，主色青绿 `#00E0A0`，警告 `#FFC24B`，危险 `#FF4D5E`，文字 `#E6EDF3`/`#7D8B99`。渐变用几条水平色带伪造（成本极低，观感提升明显）。
- **启动动画**：Log 标题淡入 → 依次自检 `LCD ID` / `MPU6050 ID` / `陀螺仪零偏标定(进度条)`，任一失败就在屏上红字报错并进串口，不会黑屏让你猜。
- **按键**：KEY0=归零校准（当前姿态记为 0°）；KEY1=暂停/继续；KEY_UP=切换 互补滤波 / 纯加速度 模式（方便你对比两种曲线）；KEY2=切换倾角显示量程(±5°/±15°/±30°，影响气泡灵敏度和量程条)。
- **LED**：LED1 1Hz 心跳=程序在跑；LED2 常亮=已水平(|倾角|<0.5°)。
