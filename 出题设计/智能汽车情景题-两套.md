# 题一：车身灯光控制单元（BCM）原型

## 0. 文档约定

| 符号 | 含义 |
|---|---|
| `LEDx = 1` | 该灯**点亮**（电气上 PF9/PF10 输出低）|
| `BEEP = 1` | 喇叭**鸣叫**（PF8 输出高）|
| `T_blink` | 转向/双闪一个完整闪烁周期 = **1000 ms**（亮 500 / 灭 500）|
| 状态变量 | `turn ∈ {OFF, LEFT, RIGHT}`、`hazard ∈ {0,1}`、`rear ∈ {0,1}`、`drl ∈ {0,1}`、`estop`（瞬态）|

**所有时间容差统一为 ±5%（表中另注明的除外）。**

## 1. 情景

整车厂 BCM 原型验证。用一块 STM32F407 开发板实现**车灯逻辑 + 故障保护**原型，供标定前功能演示。

**约束：上电后不按 RESET、不重烧固件，一次演示完所有功能项。**

## 2. 硬件资源

| 资源 | 引脚 | 电气特性 |
|---|---|---|
| 左转向灯 | PF9 | 低电平亮，共阳 + 1k 限流 |
| 右转向灯 | PF10 | 同上 |
| 喇叭 | PF8 | **高电平响**，NPN 驱动（极性与灯相反）|
| 转向开关 | PE4 | 按下 = 0，内部上拉，**必须 EXTI** |
| 双闪开关 | PE3 | 按下 = 0，内部上拉，**必须 EXTI** |
| 倒车开关 | PE2 | 按下 = 0，内部上拉，**必须 EXTI** |
| 急停开关 | PA0 | **按下 = 1，内部下拉**，**必须 EXTI** |
| 显示 | ILI9341 320×240 | FSMC |
| 触摸 | XPT2046 | 软件 SPI，允许使用、允许不可靠 |
| 可选 | EC11 | PC10/PC11/PC12 |

> ⚠️ 本板 **PB15 为 LCD 背光**、**PA1 为 RMII_REF_CLK**，两者不可挪用。

## 3. 系统状态定义

### 3.1 状态变量

| 变量 | 取值 | 修改来源 | 上电初值 |
|---|---|---|---|
| `turn` | OFF / LEFT / RIGHT | KEY0 循环 | **OFF** |
| `hazard` | 0 / 1 | KEY1 翻转 | 0 |
| `rear` | 0 / 1 | KEY2 翻转 | 0 |
| `drl` | 0 / 1 | 触摸屏进入/退出 | 0 |
| `self_test` | 0 / 1 | KEY0+KEY1 长按 2s | 0 |

### 3.2 灯光仲裁矩阵（自上而下，命中即停）

| 优先级 | 条件 | LED0 | LED1 |
|---|---|---|---|
| P1 | 急停进行中（300ms 内）| 0 | 0 |
| P2 | `hazard == 1` | `T_blink` 相位 | **与 LED0 同相** |
| P3 | `turn == LEFT` | `T_blink` 相位 | 0 |
| P4 | `turn == RIGHT` | 0 | `T_blink` 相位 |
| P5 | `drl == 1` | 呼吸亮度 | 呼吸亮度 |
| P6 | 其他 | 0 | 0 |

### 3.3 喇叭仲裁矩阵

| 优先级 | 条件 | 表现 |
|---|---|---|
| P1 | 急停进行中 | 0 |
| P2 | `self_test == 1` | 响 200ms 一次 |
| P3 | `rear == 1` | 按距离分段鸣叫（见 4.3）|
| P4 | 其他 | 0 |

## 4. 功能规范

### 4.1 基本功能 1 —— 转向灯（KEY0）

| 项 | 规范 |
|---|---|
| 触发 | KEY0 下降沿；去抖 ≥ 20ms，一次按下只产生一个事件 |
| 行为 | `turn` 按 OFF → LEFT → RIGHT → OFF 循环，**每按一次前进一档** |
| 闪烁 | 命中档位时对应灯以 `T_blink` 闪烁；相位自**按下时刻**重新起算 |
| 边界 1 | 关灯档：两灯立即熄灭 |
| 边界 2 | 双闪期间按 KEY0：`turn` **照常改变**，但显示由 P2 接管；双闪解除后立即按新 `turn` 显示 |
| 容差 | 周期 1000ms ± 50ms，占空比 50% ± 3% |

### 4.2 基本功能 2 —— 双闪（KEY1）

| 项 | 规范 |
|---|---|
| 触发 | KEY1 下降沿 |
| 行为 | `hazard` 翻转 |
| 显示 | `hazard=1` 时两灯**严格同相**闪烁（相位差 ≤ 5ms）|
| 恢复 | `hazard` 置 0 后**立即**按当前 `turn` 显示（`turn=OFF` 则全灭）|
| 禁止 | 双闪期间两灯不得出现相位差 |

### 4.3 基本功能 3 —— 倒车雷达提示（KEY2）

| 项 | 规范 |
|---|---|
| 触发 | KEY2 下降沿，`rear` 翻转 |
| 计时起点 | `rear` 由 0→1 的时刻 `t_rear` |
| 分段 | 以 `t_rear` 为基准的**绝对时间** |

| 阶段 | 时间窗 | 鸣叫 | 静音 |
|---|---|---|---|
| 远 | 0 ≤ t < 3000ms | 100ms | 900ms |
| 中 | 3000 ≤ t < 6000ms | 100ms | 500ms |
| 近 | t ≥ 6000ms | 100ms | 200ms |

| 边界 | `rear` 由 1→0 立即静音，`t_rear` 清零；重新启动从"远"开始 |
| 容差 | 鸣叫 ±10ms，静音 ±20ms，切换点 ±100ms |

### 4.4 基本功能 4 —— 急停（WK_UP）

| 项 | 规范 |
|---|---|
| 触发 | PA0 上升沿 |
| 动作（同一次事件内） | ① 关闭所有灯 ② 关闭喇叭 ③ `turn=OFF, hazard=0, rear=0, drl=0` ④ 清除所有计时与长按状态 |
| 静默期 | 之后 300ms 保持全灭 |
| 响应 | 按下到灯灭 **≤ 5ms** |
| 边界 | 任何状态有效，包括自检中 |

### 4.5 基本功能 5 —— 日间行车灯（DRL，软件呼吸）

| 项 | 规范 |
|---|---|
| 进入 | 触摸屏"日行灯模式"，`drl=1` |
| 曲线 | 占空比 **20% → 100% → 20%** 线性三角波，周期 **2000ms ± 100ms** |
| 两灯 | 严格同相（≤ 5ms）|
| 步进 | 每 10ms 更新一次，单步 ≤ 1% |
| 禁止 | **不得使用任何定时器（含 SysTick）** |
| 边界 | 退出时立即全灭，呼吸相位归零 |

## 5. 拓展功能

### 5.1 拓展 1 —— 亮度可调

| **恢复测试** | 双闪关闭后转向状态**原样恢复**（不能变全灭）|

### 5.3 拓展 3 —— 灯光自检（EOL）

| 项 | 规范 |
|---|---|
| 触发 | KEY0 + KEY1 同时按住 **2000ms ± 100ms** |
| 顺序 | LED0 亮 500ms → 灭 → LED1 亮 500ms → 灭 → 喇叭 200ms |
| 屏幕 | 自检中显示"自检中"，结束后显示"自检通过" 800ms |
| 结束 | 回到自检前状态 |

|---|---|

## 7. 硬性约束与违规判定

| 编号 | 约束 | 违规判定 |
|---|---|---|
| C1 | 按键必须用 EXT I | 轮询 → 该项 0 分 |
| C2 | **禁止任何定时器**（TIM1~TIM14、SysTick）产生呼吸与 PWM | 出现 `HAL_TIM_*` / `htim` → **总分 0** |
| C3 | 禁止 `HAL_Delay()` 产生波形或节奏 | 出现即判违规 |
| C4 | 演示中不得 RESET / 重烧 | 违规扣 20 |
| C5 | 按键响应 ≤ 50ms | 明显卡顿扣分 |
| C6 | 乱按/连按/多键同按不得死机 | 死机 → 总分 0 |

> `HAL_GetTick()` 允许用于**功能计时**（闪烁相位、长按判定）；但**呼吸与 PWM 的波形时基必须由 `Delay_us()` 忙等产生**，报告中需明确区分。

# 题二：泊车辅助提示系统（PDC）

## 0. 文档约定

| 符号 | 含义 |
|---|---|
| `d` | 模拟障碍物距离，单位 **cm**，范围 10 ~ 250 |
| `T(d)` | 蜂鸣周期（一个"响+停"完整循环），单位 **ms** |
| `Ton` | 单次鸣叫时长，**固定 100 ms** |
| `beep(t)` | 喇叭状态，1 = 响 |
| `t0` | 本次泊车开始的时刻 |

## 1. 情景

整车厂**泊车辅助系统（PDC, Park Distance Control）**原型验证。

没有超声波传感器，要求用**手动输入模拟距离**，验证 **HMI 提示策略**是否符合整车标定规范。

**核心要验证的不是测距，而是"距离如何映射成人能听懂的提示节奏"。**

## 2. 硬件资源

| 资源 | 引脚 | 说明 |
|---|---|---|
| 喇叭 | PF8 | 高电平响（有源蜂鸣器，**音调固定**）|
| 提示灯 | PF9 / PF10 | 低电平亮 |
| 距离减 | KEY0 / PE4 | 每次 −5cm |
| 距离加 | KEY1 / PE3 | 每次 +5cm |
| 泊车开关 | KEY2 / PE2 | 进入/退出泊车模式 |
| 急停 | WK_UP / PA0 | 按下为高 |
| 显示 | ILI9341 | 距离、节奏、波形图 |
| 可选 | EC11 | 连续调节距离（±1cm）|

## 3. 核心概念：时域间隔调制

### 3.1 三种"调制"的区别

| 调制方式 | 改什么 | 听感 | 汽车上用在哪 |
|---|---|---|---|
| 频率调制 | 改 `f` | 音调变高变低 | 报警语音、音乐 |
| 幅度 / 占空比调制 | 改 `Ton`（周期不变）| 声音变短、变"叽" | 音量调节 |
| **间隔调制（本题）** | **改 `T`，`Ton` 固定** | **越来越急** | **倒车雷达 ✔** |

### 3.2 它和 PWM 的关系

```
信号：  ▔▔▔▁▁▁▁▁▁▁▁▁▔▔▔▁▁▁▁▁▁▁▁▁
        ↑Ton↑  ←  T(d)  →
```

| 项 | PWM（GPIO 实操题）| 本题的间隔调制 |
|---|---|---|
| 周期 | 固定 1ms | **变化** `T(d)` |
| 高电平时间 | 变化（占空比）| **固定 100ms** |
| 变化的是 | 占空比 | **周期** |
| 感知 | 亮度 | **节奏** |

**关键**：`Ton` 固定时，占空比 `Ton/T(d)` 会随距离**自动变化**——
所以间隔调制**同时也在调制占空比**，但人耳听到的是"节奏"而不是"音量"。
**为什么？** → 见 §10 Q2

## 4. 信号模型（硬性要求）

```c
/* d 单位 cm，30 ≤ d ≤ 200 时有效 */
T(d) = 200 + (d - 30) * 1000 / 170      /* 200ms ~ 1200ms，线性 */

beep(t) = ( ((t - t0) % T(d)) < Ton ) ? 1 : 0
```

| 距离 `d` | `T(d)` | 占空比 | 听感 |
|---|---|---|---|
| **≥ 200cm** | — | 0 | **不响** |
| 200cm | 1200ms | 8% | 很慢 |
| 150cm | 906ms | 11% | 慢 |
| 100cm | 612ms | 16% | 中 |
| 60cm | 376ms | 27% | 快 |
| **30cm** | **200ms** | **50%** | **很急** |
| **< 30cm** | — | 100% | **连续长鸣** |

> 数值必须**严格按公式计算**，不接受"大致差不多"。

## 5. 功能规范

### 5.1 基本功能 1 —— 距离模拟

| 项 | 规范 |
|---|---|
| 范围 | 10 ~ 250 cm |
| 步进 | KEY0/KEY1 每次 ±5cm；编码器 ±1cm |
| 限位 | 超出范围**停止变化**，不得回绕 |
| 显示 | 实时显示 `距离 xxx cm` |
| 响应 | ≤ 30ms |

### 5.2 基本功能 2 —— 泊车模式开关

| 项 | 规范 |
|---|---|
| 触发 | KEY2 下降沿，翻转 |
| 进入 | `t0` = 当前时刻，开始按 §4 发声 |
| 退出 | 立即静音，屏幕提示"泊车关闭" |
| 上电初值 | **关闭** |

### 5.3 基本功能 3 —— 间隔调制发声

| 项 | 规范 |
|---|---|
| 发声规则 | 严格按 §4 公式 |
| `d ≥ 200` | **不响**（不是长响）|
| `d < 30` | **连续长鸣**（`beep=1` 不翻转）|
| 距离改变 | **下一个周期**生效（不打断当前周期）|
| 容差 | `T(d)` ±5%，`Ton` ±10ms |

### 5.4 基本功能 4 —— 视觉同步

| 要求 | 说明 |
|---|---|
| 雷达条 | 距离越近条越满（10 格，1 格 = 24cm）|
| **节奏波形** | 屏幕画出 `beep(t)` 时序图（≥ 2 个周期），周期性刷新 |
| 数值 | 显示 `距离`、`T(d)`、`占空比` |

### 5.5 基本功能 5 —— 遮挡保护

| 项 | 规范 |
|---|---|
| 触发 | WK_UP |
| 动作 | 立即静音 + 退出泊车模式 + 两灯全灭 |
| 静默期 | 之后 300ms 不响应泊车操作 |
| 响应 | ≤ 5ms |

## 6. 拓展功能

### 6.1 拓展 1 —— 节奏平滑（防跳变）

**问题**：距离从 200cm 跳到 60cm，`T` 从 1200ms 直跳 376ms，节奏会"卡一下"。

要求对 `T` 做**一阶低通**：

```c
T_now = T_now + (T_target - T_now) / 8;     /* 每 50ms 更新一次 */
```

| 验收 | 预期 |
|---|---|
| 距离突变 | 节奏在 300ms 内平滑过渡，听不出卡顿 |
| 距离缓变 | 与直接映射差异 ≤ 10% |

### 6.2 拓展 2 —— 静音键

KEY1 长按 1.5 秒：**只静音，不退出泊车模式**；再长按恢复。

### 6.3 拓展 3 —— 分级提示

| 距离 | 喇叭 | 灯光 |
|---|---|---|
| ≥ 200cm | 不响 | 全灭 |
| 60 ~ 200cm | 按公式 | 全灭 |
| 30 ~ 60cm | 按公式 | **LED0 与蜂鸣同步闪** |
| < 30cm | 连续长鸣 | **LED0 + LED1 同步长亮** |

## 7. 硬性约束

| 编号 | 约束 | 违规判定 |

## 10. 分析题（答辩，每题 5 分）

### Q1：为什么改间隔而不是改音调？

> 驾驶员注意力分散时，对**节奏变化**的敏感度远高于对音调变化的敏感度；且音调变化容易被误判为设备故障。

### Q2：`Ton` 固定 100ms 时，占空比随距离怎么变？为什么听到的是"急"而不是"响"？

> `占空比 = 100 / T(d)`，从 8% 变到 50%。
> 但人耳判断的是**事件发生的时间间隔**（节奏），不是能量占比——
> 这与 PWM 调光时人眼判断"平均亮度"**恰好相反**。

### Q3：如果改成"占空比恒定 20%"，声音会变成什么样？

> `Ton = 0.2 × T`，距离越近 `Ton` 越短（200ms 周期时 `Ton` 只有 40ms），
> 声音从"滴"变成"叽"，**提示效果反而变差**——说明"固定脉宽、变周期"才是正确做法。

### Q4：距离突变时为什么要平滑？

> `T` 的阶跃会让节奏出现停顿或错拍，驾驶员会以为系统卡死；
> 一阶低通相当于给节奏加"惯性"，符合听觉预期。

### Q5：用定时器怎么做？为什么题目禁止？

> 定时器可用"单脉冲模式 + 每次重装 ARR"实现变周期；
> 禁止的原因：本题考的是**用变量代替定时器**——能不能把"周期"变成主循环里随时可改的一个数值。

# 附：两题的难度阶梯

```
GPIO 实操题（第一套）
    功能基本互斥 → 考"单功能实现"
          ↓

    多状态并发 → 考"状态保存与恢复 + 优先级仲裁"
          ↓
PDC 提示题（第三套）
    参数连续映射 → 考"定量建模 + 时域调制 + 平滑滤波"
```

| 维度 | 第一套 | 第二套 | 第三套 |
|---|---|---|---|
| 功能关系 | 互斥 | 并发 | 连续参数驱动 |
| 核心考点 | 单功能 | 仲裁与恢复 | **定量映射 + 概念迁移** |
| 时序容差 | ±50ms | ±5% | **±5%（公式级）** |
| 判定方式 | 目视 | 秒表 + 示波器 | **示波器测周期/占空比** |
| 分析深度 | 实现层 | 架构层 | **为什么这样设计** |
| 新增难点 | 软件呼吸 | 双键长按、分段节奏 | 间隔调制、平滑滤波 |

## 共同硬性约束（三套一致）

1. **全程不使用任何定时器（含 SysTick）**产生波形/节奏
2. 按键必须用 **EXTI 外部中断**
3. **不按 RESET、不重烧固件，一次演示完**
4. 乱按、连按、多键同按不得死机
