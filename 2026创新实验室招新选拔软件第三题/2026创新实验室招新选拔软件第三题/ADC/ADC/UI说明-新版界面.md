## 三、冻结 + 双游标

- 点一下波形区，或点底部「冻结」，当前帧冻结（黄底「冻结」亮起）。
- 冻结后底部原来的「上升/下降」位置变成 **X / Y** 两个游标模式按钮：
  - **X 模式**：两条黄色竖直虚线 A / B，读时间差和频率；
  - **Y 模式**：两条黄色水平虚线 A / B，读电压差（幅值）和 A/B 绝对电平。
- X 模式顶部小面板显示：

  ```
  dT 5.000ms  F 0.200kHz
  ```

  - `dT = |xA-xB| × (10 × TB) / 236`
  - 换算频率 `F = 1 / dT`
  - 精度：TB=250us 时每个像素约 10.6us；测 1kHz（1ms）误差约 1%。
- Y 模式顶部小面板显示：

  ```
  CH1 dY 0.500V A1.00 B1.50
  ```

  - 使用当前显示通道的 V/div 和垂直中心换算电压（两路都开时默认 CH1，可关掉 CH1 后测 CH2）；
  - A/B 是两条水平游标对应的绝对电压，`dY = |VA - VB|`。
- 冻结状态下再点波形区：X 模式离哪条竖线近就移动哪条，Y 模式离哪条横线近就移动哪条。
- 拖动时采用“抓住相对偏移”的方式：按下不会把游标瞬移到手指位置，而是保持按下时游标与手指的相对距离，随后跟手移动，所以不会跳变；移动过程只擦除/重绘游标层、网格和波形，不整屏填充，因此不会闪屏。
- 再点「冻结」退出，恢复实时波形。

## 五、三种触发模式在屏幕上的行为

| 模式 | 行为 |
|---|---|
| 自动 | 每帧都更新；触发不到时也从帧头开始画，基线可见 |
| 正常 | 只有 `ADC1_FindTrigger()` 找到触发才更新显示帧，否则保持上一帧；无触发期间同时暂停自动量程，时基/V/div/中心都不会把上一帧重新拉伸 |
| 单次 | 点「单次」武装；捕获一帧后停止（`STOP`），显示和量程保持；再点一次重新武装 |

显示帧统一由 `cmd.c` 的 `CMD_DisplayFrame()` 提供，屏幕测量和串口 `MEAS?` 用同一帧，所以两边数值一致。

## 七、连续采集修复（ADC 停流）

如果出现「只有按复位才更新一帧、之后波形不动」，根因是 **自动时基在运行中改 TIM3 的 ARR**：`TIM3->EGR=UG` 会在 ADC 正在转换时注入一次触发，产生 overrun（`ADC_FLAG_OVR`），DMA 流随后停住，看起来就像只采集了一段。

`adc.c` 已按下面的方式修：

- `ADC1_SetSampleRate()` 改成**先停 ADC/DMA 和 TIM3 → 改 ARR → 清 OVR/EOC/DMA 标志 → 重新使能 ADC/DMA → 等 10us → 再开 TIM3**，不再在 ADC 运行中直接改 timer。
- `ADC1_CopyFrame()` 每次进来先检查并清 `ADC_FLAG_OVR`，即使偶发 overrun 也能自己恢复，不用按复位。
- 采样时间固定为 15 cycles（在 21MHz 下 1.29us），500kSa/s 也能满足；不再在运行中改 ADC 采样周期。
- `cmd.c` 里原有的「无帧超时自动 `ADC1_Init()`」保留，作为最后兜底。

## 八、自动量程比较器（防抖/迟滞）

原来的自适应每 5 帧按 `V/div = Vpp × 3/16` 直接重算，测量值一抖，量程就跟着变。现在改成「比较器 + 迟滞 + 防抖」：

- **横向密集度比较器**（时间量程 / 采样率）
  - `frame_cycles = 频率 × 2048 / 采样率`（整帧里有多少个周期）
  - `frame_cycles > 12`：太密 → 提高采样率、缩短捕获窗口，目标 **8 个周期/帧**（减小时间量程）
  - `frame_cycles < 4`：太疏 → 降低采样率、加长捕获窗口，目标 **8 个周期/帧**（加大量程）
  - `4 ~ 12` 之间：**采样率保持不动**
  - 屏幕显示窗口单独固定为 **2.5 个周期**（`CMD_CYC_TARGET`），所以看起来不会忽多忽少
- **竖向占屏比较器**
  - CH1、CH2 各自算 `fill = Vpp / (8 格 × 当前 V/div)`；
  - 两路同时显示时取**两路都放得下的较大 V/div**，让左右两条电压轴使用同一个分度值；单路显示时只按这一路换档；
  - CH1 的电压刻度在左侧（青色），CH2 在右侧（绿色）；只开 CH2 时 CH2 刻度自动移到左侧；
  - 垂直中心各自跟随自己那一路的直流偏置，并量化到 V/div 的整数倍，所以刻度值是 0、0.5、1.0、1.5、2.0 这种规则值；
  - `fill > 0.85`：波形太满 → 升 V/div（量程变大、波形变小）
  - `fill < 0.45`：波形太小 → 降 V/div
  - `0.45 ~ 0.85` 之间：**保持不动**（目标占屏 70%）
  - 这里的 `Vpp` 是**交流峰峰值**，垂直中心用**直流偏置 `(Vmax+Vmin)/2`**，两者分开，直流不会把档位带跑
  - 自动 V/div 会量化到 `100/250/500/1000/2000/2500/5000 mV`，时间档量化到 `1/2/5/…/250/…/20000 us`，保证坐标轴分度规则；X 轴单位按 timebase 统一成 ms 或 us。
- **防抖**：同一方向连续 3 次超出门限才动作一次；一次更新只动一个轴，避免横竖同时跳。
- **低频率兜底**：如果一帧里不足一个周期（`freq<0.5Hz`），每 3 次把采样率减半，直到能测出周期，再按 8 周期/帧收敛。
- **无信号 / DC**：直接保持当前量程，不在噪声上反复找档。
- **冻结时暂停自动量程**，保证游标读数不被改档打断。
- **顶栏「自动」胶囊可以点按开关**：关掉后完全手动；点菜单里的时基/垂直键也会自动退出对应自动项。
- 门限都在 `cmd.c` 顶部：`CMD_CYC_HI/LO`、`CMD_MEAS_CYCLES`、`CMD_FILL_HI/LO`，想调松紧改这里即可。

## 九、DSP FFT 测频 + 直流/交流分离

- `measure.c` 用 CMSIS-DSP 的 **2048 点 `arm_cfft_f32`**（`arm_cfft_sR_f32_len2048`）：
  - 输入先减直流均值，再加 Hann 窗，抑制频谱泄漏；
  - 找最大峰，对峰值左右三根谱线做**抛物线插值**，得到亚 bin 频率；
  - 和过零点测频结果融合：两者相差 ≤12% 时用 FFT 结果，否则保留过零点结果（防止谐波/噪声把峰偷走）；
  - FFT 每 4 次测量刷新一次（UI 100Hz 调用也不卡），采样率变化时自动重算。
- **8 周期/帧**的自动时基保证 FFT 分辨率（例如 1kHz 时 fs≈256kSa/s，bin≈125Hz，插值后误差 <1%）。
- 因为 ADC 只能输入正电压，交直流分离全部基于**输入的最高/最低电压**：
  - `Vmax`、`Vmin`：一帧内的最高、最低电压（V）
  - `Vpp = Vmax - Vmin`：**交流峰峰值**（例：Vmax=2.0V、Vmin=1.0V → 1.0V）
  - `Vbias = (Vmax + Vmin) / 2`：**直流偏置**（同例 → 1.5V；如果是 1Vpp + 1V 偏置，则 Vmax=1.5V、Vmin=0.5V → Vpp=1.0V、Vbias=1.0V）
  - `Vrms_ac = sqrt(mean(v²) - mean(v)²)`：交流有效值（真实 AC RMS）
  - 注意：`Vmax - Vmin` 是 **Vpp**，不是直流偏置；直流偏置是上下峰的中点。
- 正电压约束：`Vmin` 必须大于 0，否则负半周被 ADC 削掉，Vpp/AC 会偏小；此时要给信号加足够直流偏置（至少 `Vpp/2`），软件无法从削顶波形恢复被削掉的负峰。检测到正弦/三角波在 0V 或 3.3V 附近有平顶时，`CLIP=1`，屏幕「直流偏置」卡会显示红色 `*` 号提醒。
- 自动量程的设置已经分离：**V/div 用 Vpp（交流）**，**垂直中心用 Vbias（直流偏置）**，所以 1～2V 直流偏置不会让交流档位来回跳。
- 串口 `MEAS?` 同时给出：`VPP / MAX / MIN / DC`（真实均值）/ `BIAS`（上下峰中点）/ `AC` / `CLIP`。
- FFT 缓冲 16KB（2048 复数 float），ZI 从 35KB 增加到约 50KB，F407 的 128KB SRAM 余量充足。

## 十、双通道同时采集（拓展 1）

- **真正同时采样**，不是轮流采两次：
  - ADC1（PA4/IN4）和 ADC2（PA5/IN5）配置为 `ADC_DualMode_RegSimult`；
  - 同一个 TIM3 TRGO 同时启动两个 ADC；
  - 公共数据寄存器 `ADC->CDR` 一次给出两个 16 位结果（ADC1 低 16 位、ADC2 高 16 位），
    DMA2 Stream0 用 **32 位 Word / DMA mode 2** 一次搬走一对数据。
- 两路用**同一个触发点**显示（优先 CH1 触发，CH1 找不到时用 CH2），因此两条波形的时间关系是真实的，不是各自独立对齐后拼在一起。
- 颜色：**CH1 青色 `0x07FF`，CH2 绿色 `0x07E0`**；参数卡边框/CH 标签同色。
- 每路单独做 FFT + 过零点测频、Vpp、直流偏置、类型；FFT 缓存按通道分开，不会把 CH1 的频率套到 CH2。
- **P/D 算法两路完全共用**：PA4（CH1）和 PA5（CH2）都调用同一个 `MEAS_Compute()`，`P = Vmax - Vmin`、`D = mean(v)`、`BIAS = (Vmax + Vmin) / 2` 没有第二套公式。PA4 读数若和 PA5 不一致，优先查 PA4 的输入链路（PA4 是 DAC1_OUT，代码已把 DAC 通道和输出缓冲都关掉；确认信号接 J4 第 5 脚而不是第 1 脚 R_ADC；信号源负载和共地）。
- 自动量程：两路同时显示时使用**同一个 V/div**（取两路都放得下的较大档），左右刻度分度值一致；垂直中心各自跟随自己的直流偏置并量化到 V/div 整数倍。只开一路时该路自己换档，刻度移到左侧。
- 自动时基以可见通道为基准（两路时 CH1 优先，CH1 关闭时用 CH2）。
- **通道显示开关**：点击 CH1/CH2 参数卡切换；开启时卡片边框/文字高亮并显示波形，关闭时卡片变灰显示 `OFF`、不画该路。两路叠加或单路单独显示都支持；只开 CH2 时，CH2 自己完成 V/div、中心、触发电平和自动时基的自适应。
- 串口 `MEAS?` 返回两路：
  `MEAS:CH1,F=...,VPP=...,DC=...,BIAS=...,T=...;CH2,...`
- 接线：
  - CH1 → J4 `STM_DAC`（PA4）
  - CH2 → J4 `STM_ADC`（PA5）
  - 两路信号源必须与板子共地；**两路的输出负载设置必须一致：要么都 High-Z，要么都 50Ω**。一路 50Ω、一路 High-Z 会让实际到板子的电压差 2 倍，表现为 VPP/VDC 一起差一倍，这不是 P/D 算法问题。

## 十一、THD / 谐波分析（拓展功能 2）

- 入口：**控制面板顶栏「THD」**按钮（在「校准」左边）；进入后全屏为谐波分析页，右上角「返回」回控制面板。
- 输入频率只接受 **1 / 2 / 3 / 4 / 5 kHz**（按 1kHz 步进）；频率偏差超过约 8% 时页面显示 `OUT OF RANGE (1..5kHz)`。
- 分析使用和测频相同的 **CMSIS-DSP 2048 点 `arm_cfft_f32`**：
  - 去直流、加 Hann 窗；
  - 在基波和 2/3/4/5 次谐波对应频点附近搜索峰值；
  - 单边幅值 `A = 2·|X| / sum(window) · 3.3/4096`；
  - `THD = sqrt(H2²+H3²+H4²+H5²) / H1 × 100%`。
- 页面显示：
  - 当前通道、基波频率、THD 百分比；
  - **H1～H5 五根柱状图**，柱高按 H1 归一化，柱顶标出各自幅值（V）；
  - 底部 H1～H5 标签。
- 每 5 个显示帧刷新一次 FFT/柱状图；页面的标题、面板、H1～H5 标签只在进入时画一次，后续只更新信息行、柱高和柱顶数值，不整屏填充，不会闪屏。
- 当前通道取 CH1；CH1 关闭时自动取 CH2，和屏幕参数卡的选择一致。

## 十二、VOFA+ 双通道显示

- 目前串口流是 **固定两列**，格式：

```text
mv1,mv2
mv1,mv2
...
```

  每行一个采样点，**CH1、CH2 固定两列**；即使屏幕上关掉某一路，列数也不变，VOFA 不会因为列数变化只显示一路。
- 数值单位是 **mV（0～3300）**，不是 0～4095 原始 ADC 码；VOFA 的 Y 轴请设 **0～3300**。
- VOFA+ 设置：
  - 协议选 **FireWater**（不是 JustFloat / RawData）；
  - 波特率 **460800**；
  - 通道数设 **2**；
  - 数据格式就是 `ch1,ch2\n`。
- 每帧最多 256 点，460800 下一帧约 2.5 KB，约 18 帧/s；VOFA 显示会比屏幕略慢，这是串口带宽限制，不是采集卡顿。
- **VOFA 波形和屏幕不完全一样是正常的**：
  - 屏幕每路独立自动 V/div、独立垂直中心；VOFA 是同一根 0～3300 mV 的 Y 轴，两路的直流偏置会直接体现在高度上；
  - 屏幕用每像素 min/max 包络画，VOFA 是 512 点折线，高频细节会略有差异；
  - 屏幕自动时基按 2.5 个周期显示，VOFA 的 X 轴是采样点序号，不是时间轴；
  - 触发点、时基窗和中值滤波两边是同一份显示帧，所以波形形状/相位是一致的。

## 十三、信号源改变后 2 秒内更新

- **AUTO 模式不再无限保持旧帧**：之前触发丢失时 `s_trig_miss` 只在 else 里自增，导致 `s_disp_found=1` 时永远停在旧帧；现已改成**最多保持 1 帧**，随后立即自由刷新。换信号源/拔掉信号后，显示帧和参数卡在几十毫秒内跟着新帧更新。
- 屏幕参数卡（频率/Vpp/DC/类型）每来一个显示帧就重算一次；FFT 缓存每路最多 4 次测量刷新一次，通常 <100ms。
- 自动量程/时基的防抖是 3 次测量（约 150ms），即使换量程也在 2s 内稳定；读数本身不依赖量程防抖，先更新。
- 串口 `MEAS?` 的回复优先于 VOFA 原始波形：UART 当前帧发完后先发测量回复；460800 下 2048 点一帧约 0.2s，所以 `MEAS?` 回复通常在 0.3s 内，最慢也 <2s。
- 冻结/单次/正常模式是“故意保持”，不在此条实时刷新范围内；测试这条请用 **AUTO + 未冻结**。
- 建议实测：1kHz/1Vpp 稳定后，把信号源改成 5kHz/2Vpp，秒表开始计时；屏幕两路参数卡应 <0.5s 变化，`MEAS?` 回包应 <1s 更新。

## 十四、验收前注意事项

1. **ADC 输入是双通道**：CH1 = PA4 / ADC1_IN4，CH2 = PA5 / ADC2_IN5。
   - 这块冠军 407 板的 J4 上：`STM_DAC` 脚 = PA4，`STM_ADC` 脚 = PA5，`R_ADC` 脚 = 板上电位器 AD1 的中间抽头。CH1 接 `STM_DAC`，CH2 接 `STM_ADC`，不要接 `R_ADC`。
   - 信号地和板子 GND 必须共地；两路都要在 0～3.3V 范围内。
2. **信号源负载设置**：如果信号发生器设成 **50Ω 负载**，而 ADC 输入是高阻，实际到板子的电压会是设置值的 **2 倍**。例如设 1Vpp + 1V 偏置，实际变成 2Vpp + 2V 偏置（1～3V），屏幕就会显示直流约 2V、峰值到 3V。把信号源负载改成 **High-Z / 高阻**，或者在输入端并一个 50Ω 到 GND，再测。
3. 先用万用表量 **PA4 对 GND**：应该看到 0.5～1.5V 的直流（叠加约 1Vpp 交流）；如果量到 1～3V，就是上面的 50Ω/高阻问题或偏置设置问题，不是 ADC 程序。
4. 如果万用表在 PA4 上量到 0.5～1.5V，但屏幕还是 2.x/3V，发一条 `MEAS?` 看 `MAX/MIN` 的原始换算值，再查 ADC 通道/校准。
2. **自动时基**：默认开启；屏幕显示约 2.5 个周期，整帧保留 8 个周期给 FFT/过零点测频。手动发 `TB` 或点菜单「时基」会退出自动。波形绘制按 `CMD_DisplaySpan()` 只画有效的那一段，所以自动时基下时间轴仍然对得上。
3. **串口 VOFA 现在是 460800 + 每帧 2048 点**（`main.c` 里是 `uart2_init(460800)`）：实际约 4 帧/s，仍达不到第一项「连续不丢帧」的要求。验收前建议改 921600（上位机同步改），或减少每帧点数——这点和 UI 无关，但会直接影响 10 分。
4. 如果 Keil 提示「源文件已被外部修改」，选 **Reload / 是**；当前工程是命令行 `UV4 -r` 编译通过的 0 Error / 0 Warning。
