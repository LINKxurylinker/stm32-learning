 2026 第三次软件培训 · 基础例程
 平台：STM32F407ZGT6  库：STM32F4xx 标准外设库
==========================================================

一、这个工程里有什么
----------------------------------------------------------
  CORE        启动文件、CMSIS 内核头文件
  FWLIB       标准外设库（全系列，含 adc/tim/dma 的库文件）
  SYSTEM      delay（延时）、sys（位带操作）、usart（串口1 + printf 重定向）
  HARDWARE
    LED       板上 LED
    KEY       按键
    LCD       TFT 屏驱动（lcd.c / lcd.h / FONT.H）
    TOUCH     触摸（touch.c 及 gt9147 / ctiic / ott2001a 电容屏驱动）
    24CXX     AT24C02（EEPROM，可存校准参数）
    IIC       软件 I2C（24C02 用）
  STM32F4xx_DSP_Support   DSP 库文件（含 arm_math.h 与 arm_cortexM4lf_math.lib）
                          注意：没有加进 Keil 工程，按课上步骤自己添加

二、工程里故意没有的东西
----------------------------------------------------------
  ADC 采集、定时器触发、DMA 搬运、FFT、波形绘制、界面逻辑
  —— 这些是本次培训的内容，需要自己写。
  工程能编译、能下载、能点亮屏幕、能画点、能串口打印，
  这就是你起步的「地基」。

三、main.c 干了什么
----------------------------------------------------------
  1. 168MHz 时钟、延时、串口（115200）、LED 初始化
  2. LCD 初始化并显示两行字、画一个边框
  3. 触摸初始化；若是电阻屏且没校准过，会自动进入四点校准
  4. 主循环：读触摸坐标、在屏上画线、串口打印启动信息、LED 闪烁

  下载后如果看到屏幕有字、手指能在屏上画线、串口有输出，
  说明板子、屏幕、触摸、串口全部正常，可以开始写 ADC 了。

四、常见问题
----------------------------------------------------------
  1. 编译报错 "cannot open source input file core_cm4.h"
     Options → C/C++ → Include Paths 里确认有 ..\CORE

  2. printf 没有输出
     Options → Target 勾选 Use MicroLIB；串口波特率要与 uart_init() 一致

  3. 屏幕白屏、背光亮但没显示
     F407 上 PB3/PB4 默认被 JTAG 占用，LCD 用到了这两个脚。
     在 LCD_Init() 之前把 PB3/PB4 配成普通推挽输出，
     或关闭 JTAG（保留 SWD）。

  4. 触摸点不准
     跑一次 tp_dev.adjust()，按提示依次点四个角；
     校准参数会存进 24C02，掉电不丢。

  5. 想用 DSP 库（FFT），报 undefined symbol arm_cfft_f32
     把 STM32F4xx_DSP_Support 加进工程，添加宏 ARM_MATH_CM4，
     勾选 Floating Point Hardware = Single Precision，
     并在文件里 #include "arm_math.h"。

五、引脚占用（自己加 ADC 时避开）
----------------------------------------------------------
  PA9 / PA10        USART1（TX / RX）
  LCD、触摸         FSMC 与 GPIO 一大片，具体见 lcd.c / touch.c
  LED / KEY         见 led.h / key.h
  建议 ADC 用 PA1（IN1）、PA4（IN4），两路互不干扰

六、上手顺序
----------------------------------------------------------
  第一天  串口打印一个 ADC 值，拧电位器看数在变（软件触发、单通道）
  第二天  改成定时器触发 + DMA，用 vofa+ 看波形
  第三天  算频率、峰峰值、直流分量
  第四天  把波形画到屏幕上，做触发对齐
  第五天  加档位、触发模式、冻结游标
