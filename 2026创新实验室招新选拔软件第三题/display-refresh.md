# 触摸屏波形显示：刷新路径深度检查与优化

> 对应要求：基本功能（五）11~14
> 代码：`USER\ui.c`（`ui_draw_wave_area`、`ui_draw_wave_dynamic`、`UI_Task`）
> 状态：已写入 Base 工程，Keil ARMCC V5.06 编译 **0 Error / 0 Warning**

## 1. 原来的问题

`UI_Task()` 每来一帧 `CMD_DisplaySeq()` 变化，就调用一次 `ui_draw_wave_area()`。原函数每次都做：

1. `ui_fill(PAN_X0..PAN_Y1)`：整个绘图面板清屏（约 269×111 ≈ 30k 像素）；
2. 重画 11 条竖网格 + 9 条横网格；
3. 重画左侧 5 个电压刻度、底部 6 个时间刻度；
4. 重画触发虚线 + “T”；
5. 逐列画波形；
6. 重画面板圆角边框。

这实际上就是“每帧全屏刷新”。LCD 是 FSMC 并口，30k 像素的填充 + 文字重绘会把一帧时间拉长，也容易看到闪变/撕裂。

## 2. 现在的分层刷新

`ui_draw_wave_area(u8 full)` 分成两条路径：

### `full = 1`：只在必要时整块重画

- 进入示波器页面；
- TB / Vdiv / 垂直中心 / 模式 / 边沿 / 触发电平 / 冻结等“静态状态”改变（`ui_scope_signature()` 变化）；
- 触摸操作改变量程或触发设置；
- 初始化。

### `full = 0`：每帧只动波形和网格

`ui_draw_wave_dynamic()` 每帧做：

1. `ui_erase_trigger_line()`：只擦旧的触发虚线和“T”；
2. `ui_erase_trace()`：按上一帧记录的轨迹擦除：
   - 峰值保持模式：逐列擦 `y0..y1`；
   - 稀疏折线模式：按上一帧的点表重画背景线；
3. `ui_draw_wave_grid()`：补回被擦掉的 20 条网格线；
4. 画新的触发虚线；
5. 画新波形，并记录新轨迹。

不再做：

- 整个面板 `ui_fill`；
- 左右/底部刻度重画；
- 面板圆角边框重画；
- 参数卡/顶栏/按钮重画。

### 坐标轴分度值

- TB 变化：只擦底部时间刻度条 + 重画 6 个时间值；
- Vdiv / 垂直中心变化：只擦左侧电压刻度条 + 重画 5 个电压值；
- 其它情况：刻度完全不动。

这正好对应“不需要全屏刷新，只刷新表格中的波形和坐标轴分度值”。

## 3. 参数卡与串口一致性

- 参数卡只在字符串变化时重画（原代码已有 `s_v_f/s_v_vpp/s_v_vdc/s_v_type` 缓存）。
- **DC 卡已从 `m.vdc_bias` 改为 `m.dc`（真实平均值）**，与串口 `MEAS:FREQ=...,VPP=...,DC=...` 对齐；`BIAS` 仍作为串口附加字段保留。
- 频率、Vpp、DC、TYPE 都来自同一帧 `CMD_DisplayFrame()` 的 `MEAS_Compute()`；屏幕和串口同源。
- 类型卡读 `CMD_GetWaveType()`（状态机稳定值），串口 `TYPE=` 也读同一状态。

## 4. 触发与撕裂

- 触发已经改为 armed + 中值 + 滞回 + 线性插值（`adc.c`），每帧起点锁在同一相位；
- 每帧只擦旧轨迹再画新轨迹，不存在整屏清空后重画造成的白屏/闪屏；
- 面板边框、网格、刻度在动态刷新中保持不变，视觉上波形是“在网格里动”，不是整页重画。

## 5. 刷新率

- `UI_Task()` 末尾 `delay_ms(20)`，所以 UI 循环上限约 **50 FPS**（1000/20）。
- 每帧动态刷新只涉及：
  - 擦旧轨迹：约 2~6k 像素；
  - 补网格：约 3.6k 像素；
  - 画新轨迹：约 3~6k 像素；
  - 触发虚线：约 0.1k 像素；
  - 合计约 9~16k 像素/帧，远低于原来 30k 面板填充 + 文字重绘。
- 正常应明显高于 10 FPS；具体数值建议上板用示波器量一个 GPIO（在 `UI_Task` 进入/退出翻转）或加一个 FPS 计数器确认。

> 如果实测低于 10 FPS，下一步可以：
> - 把逐列 `ui_fill` 擦除改成按连续列合并的矩形擦除，减少 `LCD_Fill` 调用次数；
> - 或者只对波形变化区域做局部擦除（dirty rect）。

## 6. 验收要点对照

| 要求 | 当前实现 |
|---|---|
| 11 坐标框/网格/横轴时间/纵轴电压 | 全量绘制一次，动态刷新保留 |
| 12 触发对齐、不滚动、不撕裂、不抖动 | armed 触发 + 插值 + 每帧局部擦写 |
| 13 ≥10 FPS，屏幕频率/Vpp/DC 与串口一致 | UI 20ms 循环 + 局部刷新；参数同源，DC 卡已改 `m.dc` |
| 14 改频后 1 秒内稳定 | 触发/自动量程/状态机均在 1~2 帧内响应 |

## 7. 上板检查顺序

1. 进入示波器页，确认网格、坐标框、左右刻度完整；
2. 给 1 kHz 方波，观察波形是否只在网格内移动、边框/刻度不动；
3. 切 TB / Vdiv，确认只有对应刻度条变化，面板不整块闪；
4. 切正弦/方波/三角，确认类型卡 1~2 帧内切换；
5. 串口发 `MEAS?`，核对 `TYPE`、`FREQ`、`VPP`、`DC` 与屏幕一致；
6. 改频率 1 kHz → 5 kHz → 1 kHz，确认 1 秒内稳定；
7. 如方便，用 GPIO 翻转测 `UI_Task` 实际帧率，确认 ≥10 FPS。

## 8. 相关代码位置

- `ui_draw_wave_area(u8 full)`：静态/动态共用主体；
- `ui_draw_wave_dynamic()`：每帧入口，处理刻度条变化；
- `ui_erase_trace()` / `ui_erase_trigger_line()`：局部擦除；
- `ui_draw_wave_grid()`：补网格；
- `ui_draw_voltage_labels()` / `ui_draw_time_labels()`：刻度值；
- `ui_draw_params()`：参数卡缓存与 DC 显示；
- `UI_Task()`：`delay_ms(20)` + 新帧调用动态刷新。
